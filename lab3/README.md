# ЛР3. Кластеризация

Кластеризация вин по химическому составу (Wine Dataset, UCI): 178 образцов, 13 числовых признаков, 3 сорта винограда (метки используются только для внешней оценки). Основные методы — K-means и иерархическая агломеративная кластеризация (Ward); дополнительно исследован DBSCAN.

## Содержимое

| Путь | Описание |
|---|---|
| `lab3_clustering.ipynb` | полный отчёт: введение, описание датасета, предобработка, ход работы, визуализация, заключение, источники, код |
| `wine.csv` | датасет (178 × 14) |
| `results/` | CSV: перебор k, метрики качества, компактность, исследование параметров, центры кластеров |
| `figures/` | гистограммы, корреляции, выбросы, скаттер-матрица, PCA, локоть/силуэт, дендрограмма, DBSCAN, кластеры, профили |
| `requirements.txt` | версии библиотек |

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m ipykernel install --sys-prefix --name lab3 --display-name "Python 3 (lab3)"
.venv/bin/jupyter nbconvert --to notebook --execute --inplace lab3_clustering.ipynb
```

## Итог (172 объекта после удаления 6 многомерных выбросов, k = 3)

| Метрика | K-means | Ward | DBSCAN (ε = 2.4, min_samples = 8) |
|---|---|---|---|
| Кластеров / шум | 3 / 0 % | 3 / 0 % | 2 / 26.2 % |
| Silhouette | 0.296 | 0.279 | 0.333 (без шума) |
| Calinski–Harabasz | 75.29 | 68.97 | 63.99 |
| Davies–Bouldin | 1.328 | 1.395 | 1.157 |
| ARI с сортами | 0.931 | 0.774 | 0.504 |
| Jaccard (пары) | 0.912 | 0.738 | 0.559 |

Лучший метод — K-means: 97.7 % объектов сгруппированы в соответствии с сортом, разбиение устойчиво (бутстрэп ARI 0.96).
